# 科学假设

## 假设

我推测 UC 主要影响少数肠道分类单元，整体 Shannon 多样性变化不明显。结果中 UC 样本的 _Akkermansia muciniphila_、_Ruminococcus bromii_、_[Ruminococcus] torques_ 和 _Gemmiger formicilis_ 相对丰度较低，_Lactobacillus mucosae_ 相对丰度较高。

一个可能解释是，UC 相关黏膜炎症改变黏液更新和可发酵底物供应，使黏液或丁酸相关菌减少，耐酸性乳杆菌则相对增加。这个机制目前只是假设，现有数据不能证明因果关系。

## 支持假设的结果

| 分析 | 参数 | 结果 |
|---|---|---|
| 数据检查 | 132 个样本、470 个特征 | 130 个样本具有完整 `Group` 标签 |
| Alpha 多样性 | Shannon、Observed、Simpson、Inverse Simpson、Chao1、ACE、Pielou | IBS 与 UC 的 Shannon 差异不显著，Kruskal-Wallis p = 0.170 |
| 治疗前后 Alpha | 配对 Wilcoxon，BH 校正 | UC Shannon 中位变化 = -0.074，p = 0.021，q = 0.072 |
| Beta 多样性 | Bray-Curtis PCoA | EMP 中 PCo1 = 27.7%，PCo2 = 19.4% |
| 群落差异 | PERMANOVA，999 次置换 | IBS vs UC：R2 = 0.022，F = 2.83，p = 0.018 |
| 离散度检查 | PERMDISP，999 次置换 | 疾病组 p = 0.363 |
| 差异菌属 | Mann-Whitney、相对丰度、BH FDR | 5 个分类单元的 FDR 为 0.080-0.086 |

方向最稳定的分类单元：

| 分类单元 | UC 中方向 | log2 FC (UC/IBS) | p | BH FDR |
|---|---|---:|---:|---:|
| _Lactobacillus mucosae_ | 升高 | +2.85 | 0.0048 | 0.080 |
| _Gemmiger formicilis_ | 降低 | -1.06 | 0.0060 | 0.080 |
| _[Ruminococcus] torques_ | 降低 | -1.93 | 0.0022 | 0.080 |
| _Ruminococcus bromii_ | 降低 | -1.74 | 0.0103 | 0.082 |
| _Akkermansia muciniphila_ | 降低 | -2.51 | 0.0143 | 0.086 |

由于没有分类单元达到 BH FDR < 0.05，这仍然是一个探索性假设，不能作为已确认的生物标志物或因果机制。

## 怎样验证

独立队列可以用绝对定量或宏基因组测序重复这些方向，并在校正抗生素、药物、肠道传输时间和批次后检查这些菌与炎症指标的关系。如果方向相反，或结果主要由技术变量解释，我会修改或放弃这个假设。

## 局限

该教学数据属于组成型数据，只凭相对丰度无法判断菌的绝对数量是否变化，也不能据此作出诊断、治疗或因果结论。
